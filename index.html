The pipeline

What "compatibility layer" actually means

01

Canonicalize

Bare domains, mixed case hosts, tracking parameters, archive-style links — all normalized into one clean, queryable URL before anything is fetched.

02

Locate

Queries the Internet Archive availability index for your date, then retries scheme and www variants so an old http-only site still resolves.

03

Replay

The nearest capture opens in a sealed viewer. The Wayback Machine rewrites the page's own links and assets, so internal navigation keeps working.

Uses the public archive.org/wayback/available endpoint. No key, no account, no server of ours in the middle.

curl "https://archive.org/wayback/available?url=example.com×tamp=20100101"
